## Описание проекта
Реализация и настройка автоматизированного workflow для тестирования и публикации приложения в DockerHub. В основе приложения находится имитация работы системы доставки посылок клиентам, с сохранением данных в базе sqlite. Автоматизация включает процессы проверки работоспособности кода и его дальнейшей контейнеризации для удобного развертывания.
